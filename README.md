# 🚀 Data Analysis & Big Data Portfolio

Bienvenido a mi repositorio de proyectos desarrollados en el marco del **Máster en Data Analysis & Big Data**. 

Este espacio reúne análisis exploratorios de datos (EDA), pipelines de procesamiento masivo, modelos de Machine Learning y proyectos finales orientados a resolver problemas de negocio mediante el uso de datos a escala.

---

## 🛠️ Tecnologías y Herramientas

### **Big Data & Procesamiento**
* **Frameworks:** Apache Spark (PySpark, PySpark SQL, PySpark.pandas)
* **Manipulación de Datos:** Pandas, NumPy

### **Machine Learning & Analítica**
* **Librerías:** Spark MLlib, Scikit-Learn
* **Modelado:** Regresión, Clasificación, Clustering, Análisis de Series Temporales

### **Visualización & Dashboarding**
* **Python:** Seaborn, Matplotlib

### **Entorno & Infraestructura**
* **Lenguaje:** Python 3.x, SQL
* **Gestión de Entornos:** Conda / Miniconda, Docker
* **Control de Versiones:** Git & GitHub

---

## 📚 Estructura de Proyectos

El repositorio está organizado por módulos temáticos y proyectos independientes:

| Proyecto / Módulo | Descripción | Tecnologías Clave | Estado |
| :--- | :--- | :--- | :--- |
| **`01_Procesamiento_y_EDA/`** | Análisis exploratorio, tratamiento de nulos y *feature engineering* a gran escala. | PySpark, Pandas, Seaborn | 🟢 Completado |
| **`02_Machine_Learning_PySpark/`** | Construcción y evaluación de modelos predictivos usando Spark MLlib. | PySpark MLlib, SQL | 🟢 Completado |
| **`03_Data_Pipelines_ETL/`** | Ingesta, transformación y almacenamiento eficiente de datasets complejos. | Python, PySpark SQL, Parquet | 🟡 En desarrollo |
| **`04_Proyecto_Final/`** | Solución end-to-end de análisis predictivo sobre un problema real de negocio. | PySpark, Scikit-Learn, Power BI | 🔴 Pendiente |
